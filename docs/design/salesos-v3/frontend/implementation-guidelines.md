# Frontend Implementation Guidelines

- Next.js App Router + Tailwind + tokenized shadcn-style primitives.
- RTL: `dir` from locale.
- Every page: Empty/Loading/Error/Permission.
- AI: Preview badge + human approval for side effects.
- Data Grid virtualization required for large lists.
- Testing: Playwright journeys J1–J5; a11y axe on shell.
- Do not claim Production GO from UI alone.
