# Accessibility (Program Standard)

## Requirements

- WCAG 2.2 **AA**
- Full keyboard paths for shell, CmdK, Data Grid, Dialogs
- ARIA for tabs, menus, grids, live regions (toasts)
- Contrast AA for text and meaningful icons
- Screen reader: page `h1`, landmarks, label associations
- `prefers-reduced-motion`
- **RTL and LTR** first-class

## Design QA gate

No component merge without a11y checklist in [governance.md](./governance.md).
