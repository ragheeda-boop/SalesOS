# Enterprise Design Governance

| Process | Description |
|---------|-------------|
| Design Review | Spec + prototype review before FE |
| Component Approval | DS owners approve new primitives |
| Token Governance | No raw hex in app code |
| Breaking Changes | Semver on `@salesos/design-system` |
| Deprecation | Dual-run ≥1 release |
| Versioning | Tokens / components / widgets versioned |
| Release | Design Ops release notes |
| Design QA | Visual + a11y + RTL smoke |

## Roles

Design Lead · DS Engineer · FE Lead · Product · (optional) Accessibility specialist.
