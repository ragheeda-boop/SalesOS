# Enterprise Data Grid

## Features

Sorting · Filtering · Grouping · Freeze columns · Aggregation · Column presets · Density (compact/comfortable) · Saved views · Bulk actions · Virtualization · Infinite scroll · Export · Permissions · Keyboard navigation.

## Keyboard

| Key | Action |
|-----|--------|
| Arrows | Move focus |
| Space | Select row |
| Enter | Open record |
| Shift+Arrow | Range select |
| `/` | Focus filter |
| `e` | Export (if permitted) |

## Performance

Virtualize >100 rows. Server-side sort/filter for large tenants. p95 render budget tracked in success metrics.
