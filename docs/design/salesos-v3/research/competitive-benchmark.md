# Competitive Benchmark

Steal **patterns**, not brands.

| Product | Steal | Avoid |
|---------|-------|-------|
| **Linear** | CmdK primacy, density, keyboard, speed | Over-minimal for enterprise reporting |
| **Attio** | CRM object model clarity, beautiful tables | Consumer gloss over governance |
| **Stripe Dashboard** | Hierarchy, quiet chrome, status clarity | Payment-domain metaphors |
| **Notion** | Flexible layouts / databases-as-views | Infinite blank canvas for ops users |
| **HubSpot** | Deep CRM IA, sequences, reporting | Nav bloat |
| **Salesforce** | Object permissions, Lightning record pages | Complexity tax, classic clutter |
| **Rippling** | Multi-product workspace switcher | HR sprawl |
| **Ramp** | Action-oriented finance cards | Narrow domain |
| **Clay** | Enrichment / table-native workflows | Power-user only |
| **Vercel** | Project switcher, deploy clarity | Devtool aesthetic only |
| **Figma** | Multiplayer cues, component variants | Design-tool IA |
| **OpenAI** | Chat + tools pattern | Chat-only as entire product |

## SalesOS synthesis

1. **Attio/Linear tables + Stripe calm + HubSpot depth** behind progressive disclosure.
2. **CmdK + Universal Search** as primary finders.
3. **Record 360** as Salesforce-like but lighter tabs + AI rail (Preview).
4. **Workspace switcher** like Rippling/Vercel for tenants.
5. **Dashboard Engine** not static pages (Stripe + marketplace widgets).
