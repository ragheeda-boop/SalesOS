# Jobs To Be Done

## Why users enter SalesOS today

1. **Find and work a company/deal** — list → 360 → activity.
2. **See if we are on track** — dashboard / forecast / pipeline.
3. **Decide** — Decision Center / executive view with evidence.
4. **Govern** — users, flags, audit, integrations.
5. **Investigate graph/signals** — relationships, alerts.

## Why users leave / abandon

1. **Cannot find** Knowledge/Marketplace (orphaned routes).
2. **Broken data plane** — historical 500/422/404 on workflows/analytics (partially fixed; trust damage remains).
3. **AI opacity** — stubs or Preview without clear “human decides”.
4. **Nav fatigue** — 25+ flat sidebar entries; duplicate Contacts.
5. **Auth friction** on virtual staging / CORS host mix (local).
