## Overview

v1.6.0 is the **Enterprise Scale** release — production Kafka event bus, Arabic NLP pipeline, Signal Marketplace for third-party data, Knowledge Packs system, K8s deployment support, and Analytics Dashboards.

**Version codename:** Enterprise Scale

## What's New

### 🔥 Kafka LIVE Event Bus
- 3-broker Kafka cluster with KRaft mode (no Zookeeper dependency)
- Avro schema registry with schema versioning and compatibility checks
- Dead Letter Queue with configurable retry policies (3 retries, exponential backoff)
- Event sourcing for critical domains (company changes, opportunity stage transitions, NBA decisions)
- Migration bridge: dual-write to Kafka + legacy Event Runtime for 2-week transition
- Monitoring: consumer lag, topic throughput, partition health in Prometheus

### 🌐 Arabic NLP Pipeline
- Arabic-aware tokenization with沙特 market-specific enhancements
- Morphological analysis (lemmatization, stemming) for Arabic business terms
- Named Entity Recognition: Saudi companies, government entities, regions, legal forms
- Sentiment analysis tuned for B2B Arabic communications
- Stop word list: Saudi business domain-specific (500+ terms)
- 18% recall improvement in Arabic search vs baseline

### 🛒 Signal Marketplace
- Browse third-party data signals by category (company intent, financial health, market news, regulatory changes)
- Subscribe/unsubscribe to signal providers with tiered pricing
- Signal configuration: frequency, severity thresholds, delivery channels
- Signal scoring integration with NBA Decision Platform
- Provider SDK for custom signal integration

### 📦 Knowledge Packs
- Curated domain knowledge packages for rapid tenant onboarding:
  - Arabic Business Terms — standard translation glossary
  - Saudi Market — market structure, key players, regulations
  - Healthcare — KSA healthcare sector knowledge
  - Financial Services — banking, insurance, capital markets
  - Construction — project lifecycle, contracting landscape
- Semantic versioning for packs (compatible, breaking changes tracked)
- Auto-activation: packs installed on tenant creation based on industry
- Dependency resolution between packs

### 📊 Analytics Dashboards
- New `/analytics` route with dedicated workspace
- **Revenue KPIs**: total revenue, pipeline value, conversion rate, forecast accuracy with trend indicators
- **Revenue Trend Chart**: 12-month revenue trajectory with month-over-month comparison
- **Pipeline Stages**: deal distribution by stage with value breakdown
- **Forecast vs Actual**: period-over-period comparison with variance analysis
- **Export**: CSV and PDF download with company branding
- Responsive layout, RTL support, dark mode compatible

### ☸️ Kubernetes Support
- Production K8s manifests (Deployments, Services, ConfigMaps, Secrets)
- Helm charts with environment-specific values (staging/production)
- Horizontal Pod Autoscaler for API and worker services
- Resource quotas and limit ranges per namespace
- Network policies for pod-level segmentation
- Pod Disruption Budgets for high availability
- Staging namespace with full monitoring stack

### 🔗 GraphQL API
- `/graphql` endpoint with schema-first design
- Core types: Company, Opportunity, Pipeline, Analytics, User, Activity
- Queries: companies, opportunities, pipelineHealth, analytics, search
- Mutations: create/update company and opportunity, trigger analytics
- Apollo Federation-ready for future microservice separation
- Rate-limited (60 req/min for enterprise tier)

| Change | Impact | Migration |
|--------|--------|-----------|
| Kafka replaces in-memory Event Runtime | Event subscribers, legacy hooks | Dual-run period until 2026-07-28; migrate to Kafka consumers |
| Redis replaces in-memory cache | Direct `app.state.cache` access | Use `@salesos/cache` client library |

## Upgrade Guide

### From v1.5.x

1. **Database migrations**:
   ```bash
   make migrate
   ```

2. **Kafka setup** (production only):
   ```bash
   docker compose -f docker-compose.kafka.yml up -d
   ```

3. **Redis setup**:
   ```bash
   docker compose up -d redis
   ```

4. **Knowledge Packs installation**:
   ```bash
   make knowledge-packs-install
   ```

5. **Environment variables**: Add to `.env.production`:
   ```
   KAFKA_BROKERS=localhost:9092,localhost:9093,localhost:9094
   KAFKA_SCHEMA_REGISTRY_URL=http://localhost:8081
   REDIS_URL=redis://localhost:6379
   GRAPHQL_ENABLED=true
   K8S_ENABLED=false
   ```

6. **Restart services**:
   ```bash
   docker compose down && docker compose up -d
   ```

### Rollback

- Stop Kafka, fall back to in-memory Event Runtime
- Stop Redis, fall back to in-memory cache
- Restart without `GRAPHQL_ENABLED=true`
- See `docs/production_runbook.md` § Rollback Procedures
